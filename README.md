# 本地私有知识库语音问答助手

一个完全本地运行的 RAG 语音问答系统：**上传你自己的文档，用语音或文字提问，由本地大模型基于你的资料回答，并朗读出来**。所有数据不上云，断网可用。

## 特性

- **完全本地**：模型推理、向量检索、语音识别、语音合成全部离线完成
- **自定义知识库**：把任意 `.txt` / `.md` 文件丢进 `documents/` 文件夹即可
- **自定义模型**：一键切换到任意 Ollama 支持的大语言模型
- **语音 + 文字双输入**：浏览器录音，本地识别
- **流式回答 + 流式朗读**：边生成边播放，可随时打断
- **多轮对话**：保留最近三轮上下文，理解“它”“这个”等指代
- **增量索引**：文档变动只重建变化部分，不用全量重建
- **网页界面**：无需命令行操作，启动后浏览器直接使用

## 技术栈

| 模块 | 方案 |
|---|---|
| 大语言模型 | [Ollama](https://ollama.com/) + DeepSeek / Qwen / 任意模型 |
| 嵌入模型 | `bge-m3`（中文检索效果最佳） |
| 向量数据库 | [ChromaDB](https://www.trychroma.com/)（本地持久化） |
| 语音识别 | [Vosk](https://alphacephei.com/vosk/)（本地中文模型） |
| 语音合成 | 浏览器内置 `speechSynthesis` |
| Web 服务 | FastAPI + Uvicorn |

## 前置要求

- **Python 3.10+**（[下载](https://www.python.org/downloads/)，安装时务必勾选 "Add Python to PATH"）
- **Ollama**（[下载](https://ollama.com/download)），安装后会自动在后台运行
- **麦克风**（语音输入需要，浏览器首次使用会请求权限）
- 至少 **16 GB 内存**（8B 模型推荐；1.5B 模型 8 GB 可跑）

## 快速开始

### Windows

双击 `start.bat`，等待初始化完成，浏览器会自动打开。


首次运行脚本会自动完成：

1.创建 Python 虚拟环境并安装依赖

2.检查 Ollama 服务与模型（若你已手动下载好，此处秒过）

3.下载并解压 Vosk 中文语音模型（约 40 MB）

5.启动 Web 服务并打开 http://127.0.0.1:8000


## 项目文件说明与使用指南

如果你需要修改配置、更换模型或更新知识库，请参考下表了解各个文件的作用：

| 目录 / 文件 | 作用说明 | 使用建议 |
|---|---|---|
| `start.bat` | **一键启动脚本** | 每次运行项目只需双击它（Windows）或在终端运行它。 |
| `uninstall.bat`| **一键卸载脚本** | 想清空环境、重新开始时运行，会删除虚拟环境、向量库、缓存等（保留源码和示例文档）。 |
| `.env` | **环境配置文件** | 复制 `.env.example` 重命名为 `.env`。这是修改模型名、端口、检索参数**最推荐**的地方。 |
| `config.py` | **核心默认配置** | 包含默认路径、默认模型名。如果你不建 `.env`，直接改这里也可以。 |
| `documents/` | **你的知识库文件夹** | 把你的 `.txt` 或 `.md` 文档扔进这里，系统会自动读取。 |
| `data/` | **向量数据库目录** | 存放处理后的向量数据和索引清单，**不要手动修改**里面的文件。 |
| `models/` | **语音识别模型目录** | 存放 Vosk 模型，启动时若不存在会自动下载，**不需要手动干预**。 |
| `init_project.py` | **环境初始化脚本** | 检查 Ollama、下载缺失的模型、构建知识库。通常在 `start` 脚本中自动调用。 |
| `code/web_server.py` | **后端服务主程序** | 接收网页请求、执行检索、调用大模型生成回答。 |
| `code/build_index.py` | **知识库索引逻辑** | 负责读取文档、切块、计算向量并存入 `data/`。可以单独运行来刷新索引。 |
| `code/index.html` | **前端网页** | 对话界面，包含录音、播放、打断等交互逻辑。 |

### 如何修改大语言模型？

如果你觉得默认的 `deepseek-r1:8b` 太慢，或者想换更强的模型（如 `qwen2.5:14b`），请按以下三步操作：

**第一步：在终端拉取新模型**
```bash
ollama pull qwen2.5:7b
```

**第二步：修改配置文件**
在项目根目录下，找到 `.env` 文件（如果没有，复制 `.env.example` 重命名为 `.env`）。用记事本打开，找到这一行并修改：
```bash
CHAT_MODEL=qwen2.5:7b
```
*(如果你不想用 `.env` 文件，也可以直接打开 `config.py`，修改 `CHAT_MODEL = os.getenv("CHAT_MODEL", "qwen2.5:7b")` 里面的默认值。)*

**第三步：重启项目**
关闭当前运行的控制台，重新双击 `start.bat` 即可生效。

### 如何修改 / 添加知识库？


**第一步：放入文档**
打开 `documents` 文件夹。你可以：
- 删除自带的 `sample.txt`。
- 把你自己的 `.txt` 或 `.md` 文件复制进来（支持多个文件，支持子文件夹）。

**第二步：更新索引（两种方式任选其一）**
- **方式 A（推荐）**：启动项目后，在网页上方点击 **“刷新知识库”** 按钮。
- **方式 A（推荐）**：启动项目后，在网页上方点击 **“刷新知识库”** 按钮。
- **方式 B**：关闭控制台，重新双击 `start.bat`，启动时会自动增量更新。

> **文档写作建议**：尽量保持排版清晰，段落长度控制在 300~500 字。系统会自动切块，如果段落太长，检索精度会下降。

## 可调参数（`.env`）

| 变量 | 默认 | 说明 |
|---|---|---|
| `CHAT_MODEL` | `deepseek-r1:8b` | 对话模型 |
| `EMBED_MODEL` | `bge-m3` | 嵌入模型 |
| `TOP_K` | `3` | 每次检索的片段数，知识库大时调至 4~5 |
| `CHUNK_SIZE` | `400` | 单片段最大字符数 |
| `MAX_HISTORY_TURNS` | `3` | 保留的对话轮数 |
| `PORT` | `8000` | Web 服务端口 |

## 常见问题


**Q: 启动时提示 Ollama 服务未运行？**
A: 打开一个新终端运行 `ollama serve`，或确认 Ollama 托盘程序已启动。

**Q: 模型拉取很慢或直接报错？**
A: 请先关闭启动脚本，在终端手动执行 `ollama pull deepseek-r1:8b`。看到进度条 100% 后，再重新双击 `start.bat`。

**Q: 浏览器提示麦克风权限？**
A: 首次点语音按钮需允许麦克风访问。若误拒，点地址栏左侧的图标重新开启。

**Q: 语音没有声音输出？**
A: 确认系统有中文语音包（Windows 设置 → 时间和语言 → 语音），Chrome/Edge 效果最佳。

**Q: 端口 8000 被占用？**
A: 在 `.env` 中修改 `PORT` 为其他数字。

**Q: 知识库回答不准？**
A: 在 `.env` 中将 `TOP_K` 提高至 4~5，或优化文档结构（分段清晰、减少超长段落）。
